# Oddwebs Landing Page

Production-ready React + TypeScript + Vite landing page for oddwebs.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```

## Environment

Copy `.env.example` to `.env` and set:

- `VITE_CONTACT_EMAIL`

## Deployment

Build output is generated in `dist/` and can be deployed to any static host (Vercel, Netlify, Cloudflare Pages, S3 + CDN).
