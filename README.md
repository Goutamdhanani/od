## 1) Psychology of First Impressions

Key behavioral facts:
- **0.05s** to form first impression
- **94%** of trust is design-influenced
- **8 sec** average attention span
- **75%** judge credibility by design

Core principles:
- **Wow Trigger (First 3 Seconds):** Use bold motion, strong typography contrast, and one clear visual statement.
- **Cognitive Load Reduction:** Reveal information progressively instead of showing everything at once.
- **F/Z Pattern Eye Flow:** Place headline top-left, CTA top-right, and proof along scan paths.
- **Dopamine Loop:** Reward scrolling with small delights (counters, flips, morphs).
- **Social Mirror Effect:** Showcase real logos, outcomes, and testimonials to build instant trust.

## 2) Hero Section Architecture (Above the Fold)

### Hero anatomy
- Navigation with clear primary CTA
- Headline: max 2 lines, emotional + rational split
- Kinetic subtitle (typewriter cycling 3–5 services)
- Dual CTA: primary filled/glow, secondary ghost
- Floating proof chips (projects/rating/experience)
- Right-side WOW visual (3D / reel / particle scene)

### Hero element breakdown
1. **Eyebrow label** with strong contrast
2. **Power headline** (56–72px, one accent anchor word)
3. **Kinetic subtitle** (typewriter sequence)
4. **Dual CTA contrast hierarchy**
5. **Floating proof chips** with subtle breathing animation
6. **3D/video/GSAP visual** occupying right ~40%

## 3) Scroll Storytelling & Trigger Map

Scroll journey:
- **0%:** Hero WOW moment
- **15%:** Pain → Solution reframing
- **30%:** Interactive services cards
- **45%:** Social proof counters + logos + testimonials
- **60%:** Case studies (before/after + metrics)
- **75%:** Process walkthrough (3/5 steps)
- **90%:** Full-screen CTA close with low friction

## 6) Conversion Architecture

Golden rule: each extra click/form field can reduce conversion by 10–30%.

Ranked CTA types:
1. **WhatsApp direct button** (~97% CVR)
2. **Calendly/Cal.com embed** (~74% CVR)
3. **Free audit/proposal form** (~52% CVR)
4. **Standard contact form** (~23% CVR)

Urgency/scarcity elements:
- Slot counter
- Response timer
- Limited offer ribbon
- Live visitor count

## 7) Tech Stack & Execution Roadmap

Recommended stack:
- **Framework:** Next.js 14 (App Router), Astro.js (portfolio-only)
- **Animation:** GSAP + ScrollTrigger, Framer Motion
- **3D:** Three.js / React Three Fiber, Spline
- **CMS:** Sanity.io, Notion + Super.so
- **Conversion tools:** Cal.com, Tally.so
- **Performance/deploy:** Vercel, Cloudflare R2 + Images

### 4-week roadmap
- **Week 1:** Strategy, copy, wireframes, design system
- **Week 2:** Core development, hero/services/case studies, responsive
- **Week 3:** Animation polish, micro-interactions, 3D, optimization
- **Week 4:** A/B test CTAs, analytics, SEO, soft launch
